# 🎂 Happy Birthday Lexine 💖

A special birthday celebration website made with love for Lexine.

## ✨ Features
- **✨ Particle & Golden Sparkle Background**: Interactive floating ambient particles and cursor dust trail.
- **💖 Dynamic Typing Header**: "Happy Birthday, Lexine! 🎂" with animated typewriter effect.
- **🎶 Soundtrack**: "Make You Feel My Love" by Anendlessocean with background player and controls.
- **📸 Interactive Photo Gallery**: Responsive memory cards with full-screen lightbox viewing.
- **🥰 "Do You Love Us?" Game**: An elusive "No" button that flees on hover/touch, and a celebratory "YES!" button with confetti and heart bursts.
- **📱 Responsive Design**: Fully responsive across mobile, tablet, and desktop screens.
